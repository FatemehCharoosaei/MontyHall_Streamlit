# 🎯 MontyHall_Streamlit
An **interactive dashboard** built with [Streamlit](https://streamlit.io/) that visualizes and simulates the famous **Monty Hall Problem** — a probability puzzle that challenges your intuition about decision-making.
---
## 🧩 What is the Monty Hall Problem?
The Monty Hall problem is based on a game show scenario:
1. You are presented with **three doors**.  
2. Behind one door is a **car (prize)**, behind the others are **goats**.  
3. You pick one door.  
4. The host, Monty Hall, opens another door that has a goat.  
5. You now have a choice: **stay** with your original door or **switch** to the remaining one.
Mathematically, switching doors **doubles your chances** of winning (from 1/3 to 2/3).  
This app helps you visualize that phenomenon.
---
## 🚀 Features
- 🎮 Interactive game simulation  
- 📊 Real-time probability visualization  
- ⚙️ Adjustable number of simulations  
- 🧠 Statistical insights and explanations  
- 🕹️ “Stay” vs “Switch” strategy comparison  
---
## 🧠 How It Works
The app uses random simulations to show the long-term success rates of each strategy.  
You can run the game once manually or simulate thousands of rounds to see how the probabilities converge.
